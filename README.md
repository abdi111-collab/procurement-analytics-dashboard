# Procurement Analytics & Logistics Optimization Model

## Project Overview
This repository contains a data-driven **Procurement Analytics and Supply Chain Risk Assessment** tool designed to model, monitor, and optimize international logistical workflows. Utilizing a mock humanitarian dataset mapped directly to primary regional distribution hubs out of **Addis Ababa, Ethiopia**, this project demonstrates how modern business intelligence applications drive cost efficiencies, vendor accountability, and strategic sourcing.

## Key Features & Business Analytics
*   **Spend Optimization Analysis:** Tracks aggregate financial outlays across multi-million dollar asset groups to identify cost-saving efficiencies.
*   **Supply Chain Risk Management:** Monitors operational key performance indicators (KPIs), segregating delivery flows into actionable risk categories (`Delivered`, `In Transit`, `Delayed`, `Under Review`).
*   **Operational Logistics Efficiency:** Calculates rolling data on average vendor lead-time metrics to optimize critical resource deployment to regional field hubs.
*   **Audit-Ready Compliance:** Generates automated data cleaning pipelines exporting to standardized flat formats (`.csv`) for structural validation.

## Technical Architecture
*   **Language:** Python 3.x
*   **Core Libraries:** Native Python standard library processing (`csv`, `random`, `datetime`)
*   **Data Models:** Algorithmic calculation of dynamic weighted pricing arrays and conditional time-series delivery projections.

## How to Run the Script
1. Clone the repository: `git clone https://github.com`
2. Run the main processing file: `python app.py`
